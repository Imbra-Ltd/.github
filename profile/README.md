# Imbra

**Complex inside. Simple outside.**

A one-engineer software consultancy for industrial companies. We build, integrate,
and support the software between plant floor and IT — protocol stacks and test
tooling, data integration and historians, the legacy systems nobody else will
touch — on published rates or at a fixed price.

Based in Varna, Bulgaria (EU, CET+1), working remotely across Europe. Every
engagement is fully documented — architecture, runbooks, and source code are
client-owned and transferable.

Where it is going: an affordable, open ecosystem for plant data — from the
protocol stack to the historian — built by Imbra, owned by the plants that run it.
